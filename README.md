# Ironman Companion

Ironman Companion helps Old School RuneScape Ironmen plan travel, herb runs, and progression in RuneLite using their character’s current unlocks and items.

## Getting started

1. Install **Ironman Companion** from RuneLite’s Plugin Hub.
2. Log into Old School RuneScape and open the **Ironman Companion** sidebar.
3. Open your bank in game to capture your bank items. The sidebar can use that snapshot after you close the bank.
4. Use the **View** menu to choose what to work on.

## What you can plan

- **Routes** suggests travel options for supported destinations, using detected teleport items and unlocks. Use **My teleports** to see the options the plugin found. Route distances are estimates. You travel manually in game.
- **Farming** checks available herb-patch information and suggests a route using detected teleports and unlocks.
- **Slayer**, **Bossing**, and **Activities** help you review preparation, requirements, and supplies.
- **Overview**, **Skills**, **Quests**, and **Goals** help you review account progress and track what to do next. **Bank** and **Inventory** let you search the items the plugin has detected.

## Optional AI assistant

The AI assistant is off by default. To use it, enable it in the plugin settings and provide an HTTPS OpenAI-compatible endpoint, model, and API key from your provider. The other planning tools work without an API key.

AI requests send your question and available account context to the configured provider. Review the bank and quest/diary sharing options before enabling AI. Bank sharing is off by default. When Wiki lookups are enabled, the plugin also sends up to the first 200 characters of your question to the public OSRS Wiki search API.
